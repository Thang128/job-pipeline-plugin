# Private document creator

Shared templates are neutral scaffolding. First import copies the neutral CV template into `private/cv-creator/`, derives private layout CSS from the attested master-CV descriptor, and stores permitted raster assets only in that private directory.

Job overlays live under `private/jobs/`. Every stable text block in the private creator mapping has an explicit `semantic_role`. Bootstrap assigns the recognized protected role `protected_other`, leaving every block immutable and unmapped. Before comparison, review every role in `private/cv-creator/creator.json`: protected roles are `identity`, `contact`, `employer`, `date`, `education`, `layout`, and `protected_other`; only `headline`, `summary`, `experience_bullets`, and `skills` may be made editable, and their `zone` must exactly equal their reviewed role. Missing, unknown, or conflicting roles fail closed. Each claim needs unique evidence IDs resolving to private career evidence; any clause containing a quantity, date, or version must occur with the same context and unit in one cited evidence row. Automated validation does not establish semantic truth: inspect every generated preview and qualitative claim before use.

Run `.\.venv\Scripts\python.exe -B -E -s -m Pipeline.document_builder bootstrap`, review roles, and declare any required font substitutions and explicit editable mappings privately. Then run `.\.venv\Scripts\python.exe -B -E -s -m Pipeline.document_builder compare`. Comparison JSON returns safe relative side-by-side PNG paths and registered `source_sha256`. Review role mapping and every returned page, then pass exact hash to `.\.venv\Scripts\python.exe -B -E -s -m Pipeline.document_builder approve --source-sha256 HASH --confirm-user-approval`. Approval performs expensive PDF/geometry check once and binds exact semantic roles, protected block IDs, creator content, source/layout/baseline hashes, checks, and ordered artifact manifest into `approved_creator_sha256`. Routine application gates rehash that stable envelope without rendering, reparsing PDFs, or regenerating previews; any drift revokes readiness and restores review-only mode. Approval never enables automatic application submission. WeasyPrint 69.0 is only renderer. Install pinned requirements if smoke test unavailable. Builds publish PDFs and previews only under `Documents/generated/`; renderer or validation failure publishes nothing.
